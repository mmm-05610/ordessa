# Package preparation criteria

Prepare an implementation package only when the caller has supplied the exact baseline and candidate source references, one scope, a method pin, and an explicitly completed and passed review. The baseline must be available. The resulting package must preserve the source and review references and identify unresolved decisions instead of filling them in.

These are human-readable criteria. The finite admission declarations in the action are machine-facing requirements; no component claims to interpret this prose as code.

Use the supplied Spec Kit forms as output templates. Do not write project files on the user's behalf: the main agent edits the project and Ordessa retains exact references and the user's explicit actions. Package generation remains a declared operation until an application binds it.
