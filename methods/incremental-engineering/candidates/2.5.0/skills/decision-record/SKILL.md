# 从自然交流捕获决定上下文与依据

使用 document.decision_context.schema/template。只记录可取得出处；无消息ID标定位限制。逐条分类 explicit_decision/explicit_delegation/interpretation/open_question。明确上下文、范围、原话、有效性、替代关系。短回复必须结合所答问题和版本。旧记录不可无声覆盖。普通已授权实现自由不再逐项问用户。缺重要选择保持未决。通过唯一 artifact owner 留档；没有 capture adapter 则报告不可用。

资源身份以当前 work.method_ref 固定的编译资源为准，不读 latest。所有副作用使用已注册 operation、稳定 request_id 与精确refs；能力缺失明确阻塞，Skill不自造后台状态。
