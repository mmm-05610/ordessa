# 尚未批准的标准选择与校准候选

原文未选定 DID 具体编号/修订/条款裁剪，也未定 JEV 阈值。本方法2.0.0没有把旧样本0.94、1.80、0.90、0.04升级为生产规则；语义检查 satisfied 仍进入 manual。此处是供父任务审议的候选，不是批准规则。

保守标准选择方案：项目 standard-profile 应固定需求(SRS)、设计(SDD)、跨边界接口(IDD)、涉及持久数据时的数据设计(DBDD)的实际标准编号、修订与原文捕获版本，并按本次范围逐条说明适用或有接受依据的不适用。变更提案借用 ECP/NOR 分工；不能把自制模板说成符合某份官方标准。标准正文未取得、编号修订未选择、裁剪无接受时，允许提案草稿，工程合规结论保持待定。父任务需裁定具体标准及条款，不通过猜测填充 acceptance。

保守 JEV 评测方案：冻结 question/input映射/model/provider/标准及方法版本；人工审议真值集覆盖完整支持、缺依据、有效冲突、只支持一部分、新增未授权含义、删除限制、摘要隐去风险、重要未知与普通授权自由。记录每例输入/原始输出、choice概率或score/noul语义、截断/超时与费用。比较假通过和误阻塞，按业务损失选阈值并独立留出复验。样本量、损失权重、阈值、准入人及复验条件均待裁定；不写任意数字为准入线。

匹配有效评测前，真实JEV可产生意见与质量测量，不产生生产自动审核通过；missing/timeout/truncation/input不全不能pass。人工复核也不能把第一版要求的真实JEV调用替换掉。原始概率不提供自由论证；支持/不足/冲突解释由受约束reviewer引用冻结问题与原文，不伪称JEV输出了任意rationale。

第一版最终验收必须证明：真实Pi接受并使用对应方法skills/输入完成精确授权切片，真实JEV判定与原始响应/usage可追溯，受信人类确认、DID CAS应用回读、完整spec/plan/tasks、结果/验收/反馈回执连续。离线结构测试仅验证资产与边界。

当前v1确认以[明确问答决定](decisions/user-confirmation-v1.md)及外置product-chat-confirmation.v1 policy为准：获准主Agent如实记录明确问答可作为依据，不要求再次点击浮窗或独立验签。actual出处限制、agent-attested等级、exact版本/scope及正式owner回执仍需保留；旧强验证建议不再作为v1硬阻塞。
