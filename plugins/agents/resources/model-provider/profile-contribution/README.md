# Retired Model Provider Profile facet

The former `ordessa-model-provider-profile` Python package registered a
Model Provider facet through the retired `pacthold.agents.profile_services`
Profile owner. Its runtime package, facet adapter, and Profile override path
have been removed. Model Provider's independent provider catalog, native
configuration resources, and ordinary chat selection remain owned by their
current packages.

Profile-driven model application is unavailable until a separately approved
current configuration owner and provider port exist. Historical design and
release evidence remains in the specs and migration records; it is not a
runtime fallback.
