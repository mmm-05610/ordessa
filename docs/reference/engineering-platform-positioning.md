## 定位

Ordessa 是供编程 Agent 调用的软件工程任务执行与管理系统。

开发者在熟悉的 Codex、Claude Code 等工具中讨论方案，由主 Agent 调用系统提交设计变更。
系统依据 DID 规范组织设计审核，参考 Spec Kit 的文档组织方式，将通过审核的变更转为包含
规格说明、实施计划和任务清单的实施包，并关联设计版本、实施任务与验收记录，让任务有明确
的设计依据和验收标准。

在此基础上，Ordessa 封装决策单元和 Agent 执行单元，提供执行者选择、任务派发、独立审查及
进度查询能力。
