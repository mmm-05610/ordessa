# 统一操作读取：已裁定，待实现

2026-10-06 用户明确答复“采用这个最小查询范围”：当前调用者自己的操作元数据、操作与目标读权限，禁止返回输入／配置正文或触发恢复／重发。以下原提案获准作为实施语义，裁定不等于代码或验收完成。

2026-10-06。下一核心切片候选；本文件不是已发布接口，也不是已实现能力。

依据：028 核心契约已有操作查询、原操作与证据核实分离；029 要求任务 inspect/watch/result。现有持久机制已有 `core.operation-identities` 与 OperationStore，不另建任务表或操作索引。

建议第一步只增加核心公共只读查询，不扩 CLI、wire、品牌协议或主动恢复。根据 operationRef 经原索引重建请求身份，核对环境、调用者、索引与原操作一致性；操作绑定节点时同时检查原操作对象及节点的 read 权限。只有当前调用者自己的请求可读，不新增跨调用者共享授权。读取历史不要求当前 provider 在线、不调用 owner、不推进状态、不 claim、不重新发送。

最小返回白名单：原操作引用、操作类型、记录版本、原持久状态、目标节点引用、是否存在结果；不返回 intent/context、配置正文、输入正文、原生帧、内部步骤或任意 evidence。结果正文先继续使用已冻结领域查询面；统一结果投影等后续单独核对，不把历史结果当当前 actual。

原索引不存在返回明确未找到；索引存在而格式、环境、调用者、operationRef 或目标关联损坏时拒绝为不可核实。授权不足先拒，不泄露其他调用者是否存在操作。读取不改变原 Operation、Step、Usage 或请求键。无 store/可信授权时拒绝，不能以空列表表示成功。

反例：同原 operationRef 跨调用者查询、操作有读权但节点无读权、索引指向另一请求、结果未知时多次读、provider 退役后读历史、metadata 含秘密标记；每例须证明零外部调用且原持久事实不变。

本阶段暂不新增 list(target)、跨调用者授权、结果帧转换、恢复调度或 managedInput 能力广告。托管输入的公开装配还缺真实 capture/native owner/writer 与完成回写，不能因挂载一个类就声称可运行。

独立 Luna 只读复查：未发现与 028/029 实质冲突。当前 release 只释放 Usage，不删除历史 Node；Node 读取验证原持久发布与索引，不要求当前 owner 在线。因此目标节点的 read 检查只使用历史 Node 公开读面，不经过运行配置 inspection，也不要求 active Usage。“原操作”指持久 OperationStore 记录和身份索引，不意味着操作可重派或自动恢复。
