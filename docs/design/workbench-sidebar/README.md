# Workbench 统一侧栏改造

2026-09-27 · 用户已批准派发，未实施。Spec Kit 文档：[规格](spec.md)、[复用与实施方案](plan.md)、[任务与验收](tasks.md)、[执行交接](handoff.md)。

目标：把当前“可停靠面板内嵌导航”的默认外观，调整为“固定顶部/底部＋中部模块内容”的统一侧栏，参考用户提供的 Codex 截图和 ZCode 的结构。保留 Ordessa 的插件化、多区域/标签、拖动与浮层能力。

**生产修改限制在平台迁移完成后的 `packages/workbench/**`，不改公共注册 API。**根 main 当前仍有旧 `plugins/workbench` 路径，实施必须从已审阅的前端平台版本派生，不能两处同时改。本轮仅主树设计文档，不修改活动 Qoder 工作树。

“只改 Workbench”不等于能同时改变 Chat 的项目/会话内容：项目分组、置顶、最近、每组展开更多、草稿项目选择位置仍归 Chat。此批不改它们、不通过父层 CSS 偷改子插件 DOM，因此交付不会冒充整张截图已完全复刻。

不依赖尚未完成的 C8 新基础件。已有稳定 `ui` 可消费；否则复用 Workbench 当前控件/样式，不能以本批为由扩改平台 UI 包。C7/C8 的任务继续独立进行。
