## U 系列验收（全部是通用受控组件，无模型）

| ID | 必须观察的行为 |
| --- | --- |
| U01 | 消费者先加载/提供者先加载结果相同；无选择时即使唯一提供者存在也保持 missing |
| U02 | 两提供者登记，只有选定者渲染；无运行中修改选择的 API，篡改输入数组不影响冻结选择；下一次装配选 B，消费者代码不变 |
| U03 | 同 key/providerId 冲突使新批次零发布，批次内前项也不可见，原注册仍可用 |
| U04 | 相同 id/major 的不同 key 实例拒绝；其他 major 不匹配；真实构建重复 key 变异失败 |
| U05 | 同一根加载/卸载/重激活，旧实现退场，新实现得到新代次；旧 handle.dispose 不误删新实现 |
| U06 | 激活中登记后抛错，作用域回收全部 UI；消费者解绑不卸载提供者，已关闭 scope 拒绝新注册 |
| U07 | 双宿主独立；卸载一边不会污染另一边；同一宿主重复创建消费 binding 独立释放 |
| U08 | 未变化快照保持引用；订阅退订有效；单个订阅者抛错不阻断其他观察者或提交 |
| U09 | provider 卸载后、React 尚未提交移除前，保存下来的发送/审批动作零业务调用；同 ID 重激活不能复活旧动作 |
| U10 | optional missing 隐藏，required missing 有提示和汇总诊断；optional 实现抛错仍显示错误，不伪装缺席 |
| U11 | A 位置渲染抛错不影响 B；显式重试/新代次可恢复；同代次不自动循环重试 |
| U12 | 动作同步抛错/Promise 拒绝都被报告；日志没有传入的秘密标记或全文 props；accepted 不被组件当最终成功 |
| U13 | 已接纳异步动作遇 UI 卸载不被取消、不在旧组件写状态；受控草稿保留，后端 stop/close 调用计数为零 |
| U14 | 提供者未启用时领域/受控 API 仍可导入；提供者和消费者独立真实构建后共享 key 与 React |
| U15 | 空 Desktop、空 Workbench、通用 UI 服务+两个无业务扩展均通过临时 Electron 冒烟；窗口/键盘焦点行为正常 |
| U16 | 新受控接口与第三方实现只修改扩展和产品清单，平台/Workbench 源码零修改 |
