## 需要保留的实现审阅点

- 文档签名必须变成可编译的类型，特别是 P 不变型、异构 UiRegistration 工厂和不透明 UiBinding；不能以 any 抹平。
- 产品组合点的具体文件在 C 最新检查点确定；不得把选择表硬编码到通用 renderer，也不能从扩展加载顺序猜默认提供者。
- Outlet 的回调保护不能只验证 DOM 最终消失；必须覆盖撤销后 React 尚未提交的窗口。
- 共享模块不能只靠测试 aliases；缺提供者情况下的 API import 和重复 key 的变异构建都要实跑。
- 前述 Agent UI 目录设计中的独立共享组件包建议由本设计替代为“轻量 API + 注册默认实现”；消费者不直接 import src。
