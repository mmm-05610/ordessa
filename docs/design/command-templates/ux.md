# UX：管理、分配、使用

## Settings / 项目 / Profile

模板插件在 Workbench Settings 贡献自己的管理区：列表（名称、说明、来源、启用范围、修订）、编辑、参数 schema、差异/审批、归档/导入。编辑器有显式“预览展开”区，给定样例参数显示最终完整用户文本和字节大小；发布新 revision 不自动推给现有启用。项目分配可在该设置区选授权项目，无需修改 Workbench 项目树。Profile 编辑面贡献“命令模板”小节，做 inherit/enable(revision)/disable；Profile 不复制正文。卸载插件时 Settings/Profile 贡献消失、不留“故障项”，数据不删；后端缺失/失败时已打开页面给可读错误和重试，不伪装空库。

## Chat `/` 与 `+`

复用已设计的同一个输入来源面板（见 [Chat 输入规格](../chat-zcode-reuse/input-spec.md)）；模板属于可识别来源组而非新浮层系统。`/` 按光标 token 查询，`+` 不改草稿且有独立搜索。结果显示名称、说明、来源、当前固定 revision、参数提示；同名时标明“模板 / 原生 / Skill”等来源。无权限/不兼容条目显示具体禁用原因；异步单来源出错仅影响该来源，可重试。

选择模板打开紧贴输入区的参数小表单及全文预览；Enter 在建议面板先选择、在参数表单明确确认，不跳过预览；Esc 返回原草稿，焦点恢复。中文 IME Enter 不触发插入/发送。预览文本可复制，但复制不表示已应用。确认只将最终文本插入当前草稿选区，保留选区之外内容；用户可以编辑。参数值不能被日志/菜单摘要暴露，敏感值不鼓励填入普通模板，明确提示其会成为用户消息。

插入/预览期间切换项目、服务、会话、Profile，或编辑草稿/光标位置时，旧结果不能落入新上下文；给“目标已变化，重新预览”而不是后台重试。模板更新不重写已有文本。失效插件撤 UI，不清已有用户草稿。发送用 Chat 的 accepted/refused/unknown 契约，unknown 保留草稿且不自动重发。

键盘与可访问性：结果区语义列表/组标题，当前项可读来源和禁用原因；参数标签/错误指向字段；焦点仅在有效 surface，关闭回到触发器；窄窗滚动不推走输入框。全量测试需同时覆盖鼠标、键盘、IME 与触屏/无 hover 可见性。
