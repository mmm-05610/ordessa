# Chat v2：创建、输入与扩展交互规格

状态：用户确认的产品行为；本文件与 spec.md 的正文/思考/工具规格共同构成整批需求。设计依据为用户提供的 Codex/Qoder 截图；借用交互结构，不复刻其未存在的业务能力。

## US4 / 项目选择与创建

- N01 全局新会话：打开项目选择弹窗，搜索已有项目，显示其服务归属和路径，重名不混淆；提供“添加项目”进入独立表单。项目来自已有服务，不在 Chat 建第二份项目库。
- N02 项目行加号：直接打开该项目的空白对话草稿，不再问项目。空白页显示“你想在 {项目名} 中做什么？”与底部输入区。
- N03 添加项目表单：名称与源文件夹，经现有项目服务验证/创建；成功选中项目进入草稿。第一版单文件夹，不因截图引入多根项目。服务不支持创建/原生选择器时显示明确不可用原因，不伪造成功，不显示用户机器无法访问的远程目录选择器。
- N04 取消弹窗无后端会话、无通道；草稿页也不预建通道。首次发送前按既有服务重验证项目，拒绝时零通道/零初始化。用户明确完成项目创建后，即使随后放弃草稿，该项目也保留。
- N05 草稿底部紧凑显示项目与可用 Harness 选择；Profile/provider-model 由贡献者接入，不由 Chat 管配置。已有会话不开放更换 Harness。Git 分支/执行位置只在真实提供者注册时显示。
- N06 弹窗使用 Workbench 既有 overlay、焦点恢复与关闭机制；Chat 不另建全局浮层系统。项目列表加载错误可就地重试；远程结果带服务身份和请求版本守卫。

## US5 / 稳定输入区与审批

- C01 消息区单独滚动；输入区位于 Chat 视图底部，不随消息滚走，不按整个窗口 fixed 定位。空白页与已有会话使用同一输入组件。
- C02 未处理审批在输入区上方显示当前操作面，关联工具条目；同一审批不出现两份可提交按钮。处理后移除操作面，消息记录仍显示真实决定与结果；approved 不等于工具成功。
- C03 多个待处理项保留计数与选择入口，不隐藏剩余审批。失效/responding/unknown 状态按业务服务禁止或限制动作。停止回执不当成终态。
- C04 中文 IME Enter 不发送；建议面板先消费 Enter/Tab，再由输入框决定发送；Shift+Enter 换行。发送时文本/附件冻结为快照，后续输入不能被晚回包清掉。

## US6 / 加号与斜杠共用面板

- P01 点击输入框左下角 +，在输入区上方展开添加与操作面板，不直接打开文件选择器。宽度随输入区，高度不超过可用空间；覆盖消息区而不推走输入框；组内统一列表滚动。
- P02 + 为浏览入口，面板有独立搜索框且不改草稿；/ 在编辑器光标处触发，以当前 token 查询。两者共用条目来源、分组和渲染，任一时刻只存在一个面板；切换入口关闭旧入口而不丢草稿。
- P03 上下键选择、Enter 执行动作或插入、Esc 关闭。Tab 在 / 建议态可补全；+ 模式维持标准焦点导航。点击外部关闭；关闭恢复到触发控件/编辑器的有效位置，不截断中文组合输入。
- P04 分组为添加、操作、技能及其他贡献组，空组不占位。每行图标/标题/简述/来源；长文本截断但完整名称可访问。能力加载中/失败/无匹配分开，失败局限该来源，可显式重试，无定时轮询。
- P05 已安装插件不自动列入菜单，必须显式贡献。无 Goal/Plan/绘图能力时没有对应假入口。贡献者可声明 plus/slash/both，重复 ID 拒绝，同名不同来源显示来源而不覆盖。内部路由用 namespaced ID，不用显示标题。
- P06 动作区分插入原生命令、加入草稿内容、执行插件操作。插入/附件默认不发送；执行动作须明确标识，不能把本地操作伪装为 Harness 命令。未知 / 文本保持原样可输入，不能被本地菜单吞掉。

## US7 / 附件与引用

- A01 Chat 内置文件/图片入口：选择、拖入、粘贴图片进入同一校验路径；准备/就绪/失败状态可见，可删除、显式重试。图片缩略图与文件卡片可预览，缺专用预览可看名称/大小/类型，不执行文件。
- A02 文件夹仅作明确目录引用；禁止默认递归读取/上传。文件引用与实际传输内容必须区分，路径只有经服务确认对目标可访问才可发送，不能把本机绝对路径直接发给远程当作可用内容。
- A03 支持类型、单文件/总量/数量限制来自服务能力；无可靠限制或发送能力时入口带原因禁用，不能先接收再静默丢弃。变更目标后重新验证已选附件，不把不兼容附件自动删除。
- A04 草稿隔离；发送前任一附件未就绪阻止发送并指出原因。提交后 confirmed accepted 才移交内容所有权；refused 保留；unknown 保留并提示核实，禁止自动重发。未知结果不能声称释放后端可能仍引用的资源。
- A05 删除草稿附件回收本地 object URL/监听与其明确自有的暂存资源；已交接给发送记录的资源不能因 UI 卸载被删除。去重重试需要服务幂等键，不靠文件名猜重复。
- A06 本批必须有至少文件文本与图片的受控端到端内容校验，证明实际内容而非只有文件名到达对端。不接真实账号/模型；不能以图片选中预览代替附件发送验收。

## 非目标

多根项目、目录全量上传、通用资产仓库、工作流/Goal 业务、语音录制、远程文件浏览器、自动执行所有 / 命令、会话内更换 Harness。已派出的 Workbench 侧栏任务不变。
