# Chat v2 验收矩阵

以下逐项需实际证据。未具备资源/未执行记未验证，不能勾为成功。

| 门 | 正向 | 反例 / 缺席行为 |
| --- | --- | --- |
| 项目创建 | 全局弹窗选项目、项目 + 直达草稿 | 取消零通道；项目失效零初始化；同名跨服务不串 |
| 模态 | Workbench 现有焦点/关闭 | 锚点失效、卸载、网络失败可恢复，不双建 overlay 栈 |
| 草稿 | 仅首发建立目标 | 晚回包不清新文本/新附件/另一草稿；未知结果不重发 |
| 固定输入 | 消息滚动时输入不离开视口 | 窄容器/缩放/长工具不挤走发送与关闭 |
| 面板 | + 浏览搜索、/ token 过滤、稳定分组 | 空/加载/失败不混；两个入口不双开，关闭不丢文本 |
| 键盘 | 上下/Enter/Esc、+ Tab 导航、/ Tab 补全 | IME 不提交；旧 token/位置不被替换；图标按钮有可访问名称 |
| 扩展 | 第三方 fixture 同时注册两入口和独立设置 | 重复 ID 拒绝；同名不同源保留；卸载只撤自身；无 Chat 后业务仍可用 |
| 目标守卫 | 正确 location 下执行 | 查询/动作跨会话晚到、提供者换代、失效条目零错目标调用 |
| 附件 | 选择/拖放/粘贴合流、准备/预览/删除 | 超限/类型不支持显式拒绝；目录不递归读；远程不可用路径不直送 |
| 内容传输 | 文本/图片字节 hash 到受控对端一致 | 元信息无内容不能 ready；一附件失败阻发送；未知提交不自动重试 |
| 清理 | 当前草稿准备资源与 object URL 可回收 | 旧请求完成不复活删除项；accepted 记录不随视图卸载删；后加附件不误清 |
| 审批 | pending 有唯一操作面、历史保留 | resolved 退出操作面但不造工具成功；过期/跨 run 零出站 |
| 展示 | 既有正文/思考/工具行为与来源证明 | 危险 HTML/URL 无执行/自动网络；异常保留原文，工具同名不串 |
| 范围 | 新实现与公共契约/装配有明确所有者 | 不改 Workbench 活动树；不引入品牌判断、第二会话 store、私有 fs |

最终检查：任务所有未勾项有真实理由；新测试确实发现过错误实现；运行日志不含秘密与文件全文；临时进程/文件记录；来源许可保留；无模型调用、无用户服务变更、无自动 push/merge。
