# 来源、时效、覆盖与待核定项

## 证据规则

检索日期为 **2026-09-27**。这里的“当前”指本次可访问的官方文档/官方主分支，而不是保证已发布到所有发行渠道，更不是机器已安装版本。

事实优先级：目标版本官方代码/Schema 与文档 → 官方当前文档 → 官方主分支的新能力。主分支与发行版不一致时分别登记。第三方 inventory、历史对话、仓内品牌注册表不能证明上游现状。

没有扫描用户 HOME 配置或凭据；没有用 `--print`、config dump、启动原生 agent 的方式探测；没有安装、更新或重启任何 Harness。

这份索引适合检查“有哪些键没有被归类”，不能据它自动生成全部 UI，也不能据它断言删除/默认/热重载语义。八家的提取覆盖深度不同，尤其 Hermes 不能用 54 个表格标识符冒充完整配置集合。

## 已发现的文档/版本陷阱

- Codex 当前高级配置明确宣布 0.134.0 的原生 Profile 格式变化。配置参考中的兼容/限制说明不能脱离该迁移解释。
- Claude 当前文档新增 AGENTS 读取，但有明确版本门槛和入口例外；不能回写成“所有 Claude 都支持”。
- Pi 官方地址重定向且文档/包命名变化；不能无计划升级旧 adapter 所带的 Pi。
- dsh 主分支是插件树装配配置；仓内旧版本声明不是此 schema 的兼容证据。
- Qwen 的原生 extension 与 Agent Plugins v1 是不同能力集合；portable v1 会忽略若干目录。
- Kilo 当前 CLI/共享配置与旧扩展教程差异大；MCP 页面仍可见不同格式示例。目标 schema/parser 优先，不能混用。
- Qwen 官网 Edit 链接当前返回旧路径 404；本轮另外验证官方固定提交的 `docs/users/configuration/settings.md` 返回有效正文，作为字段索引来源。不能把编辑链接失效误判为配置能力不存在。

## 完成标准

一个具体配置面进入实施包前，至少具备：官方固定依据、版本条件、原生入口/作用域/合并规则、Profile 可写性裁定、应用与回读方式、两个会话隔离反例、缺失/失败语义，以及明确复用/自研边界。

大类设计可以现在审；不必等几百字段全部裁定才讨论。但“全部 Harness 配置能力已精准盘完、可无人值守实现”目前**不成立**。
