2. WHY THE conftest-IMPORT SPLIT WAS NECESSARY (found by the lane aggregate, §4b)
=====================================================================================
The first post-rename lane aggregate collected all 610 items but reported 4 failures:
  ImportError: cannot import name 'make_intent' from 'conftest'
  (.../plugins/assets/sandbox/backend/tests/conftest.py)
Cause: every package's `conftest.py` is imported by pytest under the single top-level
module name `conftest` (pytest deletes sys.modules["conftest"] before loading each new one),
so a `from conftest import X` executed *inside a test body* (run phase, after all
collection) binds whichever package's conftest was loaded last — not the file next to it.
Fix: the plain helper factories/constants moved verbatim out of
plugins/permissions/adapters/tests/conftest.py into the uniquely-named
_permissions_adapters_helpers.py; conftest.py keeps only the `families` /
`pinned_versions` fixtures. Verified line-by-line: every non-blank line of the original
conftest.py appears verbatim in helpers+conftest (no edited or dropped statement), and the
4 in-body imports stay in-body so the monkeypatch-poisoning window in
test_purity.py::test_behaviorally_no_subprocess_no_socket_no_file_open is unchanged.
