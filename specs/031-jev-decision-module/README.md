# Jev 多轮决策模块 · Spec Kit 实施包
日期：2026-10-05。状态：设计整合及交叉审查完成；不是产品实现或验收完成声明。

## 目标
构建一个独立、可替换模型提供者的决策模块。主 Agent 给出有边界的任务；模块判断是否足够清楚，再判断是否需要外置工作单元、能否复用现有单元、是否需要调整或新建，最终返回经过校验的提案。它不是另一个 Agent 生命周期内核，也不是自动执行平台。

## 效力与授权
用户授权本轮设计、独立子代理设计与主会话验收、编写实施材料。未授权安装依赖、真实 Jev/Harness 调用、源码实现、创建实施树、重启服务、提交、合并或推送。
本包位于产品主树，仅是设计权威。另一个 agent-tools 工作树是只读源码参考，不向其投递或修改其文件。
遵循本仓 Spec Kit 流程；采用 incremental-work-order 的可判定任务、独立写权、反例和证据纪律，不另建覆盖现有项目的调度系统。

## 最终交付判据
独立库可用假提供者离线运行；同一引擎可执行两套不同可信业务流程；加入一个未知名称的配置种类无需修改引擎；提案可被真实 Ordessa 只读接口核验，但模型调用和实际应用的验证必须分别授权和记账。
材料校验通过仅表示链接、任务和验收组织完整，不表示上述产品判据通过。
