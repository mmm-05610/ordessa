# 公共 UI 组织与交互合同

设计 ID：UI-FOUNDATIONS-20261004。与 frontend.md、frontend-infrastructure.md 联合使用。本文件是交付要求，不是已实现证明；参照用户提供的 Codex 截图，不依赖 Codex 私有实现。

## 1. 目标工作区

```text
Desktop 原生窗口（系统菜单、窗口控制）
└─ Workbench
   ├─ 全局导航栏（工作区入口；底部通用菜单位置）
   ├─ 当前工作区侧栏（当前工作区提供的内容）
   ├─ 主区域（页面标题、操作、正文）
   ├─ 辅助区域（右侧/底部；按需显示）
   └─ 标签、分屏、弹层与焦点管理
```

导航位置分工不是必须出现的空槽。产品决定启用哪些贡献；插件缺席时不展示无效入口。工作区、页面定义、页面实例、领域目标分别有身份；多个视图可观察同一领域目标，不因此建立多个领域 writer。工作区切换默认不销毁已接纳业务任务。

## 2. 包职责、依赖与禁止项

| 包/宿主 | 交付 | 禁止承担 |
| --- | --- | --- |
| extension-api / contracts | 中性导航、页面、菜单操作、设置贡献契约及 Token，注册返回 scope-owned 句柄 | 领域字段、Workbench 私有布局树、Electron 权限 |
| extension-runtime | 注册存续、激活失败回滚、退出撤销与受影响引用管理 | 全局业务 store、UI 设计、另造插件生命周期 |
| workbench | 工作区/导航容器、标签分屏、页面激活关闭、弹层定位叠放、焦点与设置容器；既有公共交互呈现 | 会话/项目/模型事实、插件安装账、另建业务状态机 |
| ui | 无副作用基础控件、样式 tokens、菜单和表单内容、键盘行为、可访问标签 | 第二弹层服务、业务操作判定、动态贡献注册 |
| ui-components | 可替换公共组件的注册/选择/绑定，产品选择呈现实现 | 再复制 ui、每个按钮都要求注册、替换呈现时新建业务 owner |
| native-bridge / Desktop | 受授权原生文件选择、系统菜单及窗口操作，原生布局存储适配 | 任意插件 Electron 访问、renderer 凭据 |
| connections / server-bridge | 沿用原连接身份与授权投影，提供页面可用性的真实来源 | 将 connected 冒充模型可用或配置确认 |
| products | 选用贡献/组件/主题、明确装配与依赖 | 桥内部路径、独立运行核心 |

ui 直接导入无注册/DOM/样式注入副作用，样式继续显式由产品加载。非 React 公共契约不引入 React/Electron；React 呈现使用同一服务实例。不得因组织变化创建新的顶层包；现有逻辑包内部拆分即可。

## 3. 贡献与操作

每项贡献有稳定 ID、提供者、作用域、排序、公开可用性来源；同 ID 冲突明确报错，不能后注册静默覆盖。注册句柄释放后移除对应入口，旧句柄不能移除新代贡献。
插件提供操作实现，公共操作入口供按钮/菜单/快捷键共用；操作接收捕获目标，执行前重新核可用性和原授权。展示的 when/disabled 不是授权。
沿用既有交互与命令机制，先盘点原接口；如需签名扩展，记录增量和迁移消费者，不再创建命令总线。上下文只保存 UI 目标和授权投影引用，不保存另一份当前模型。快捷键按焦点和输入法状态处理，不抢 IME 或普通输入。
会话重命名、归档、分支、账号、额度等只由插件提供；不照搬无实现的 Codex 菜单条目。

## 4. 布局、标签、弹层和焦点

沿用现有布局实现；独立区域各自滚动，主体不得被外围工具挤成不可读窄列。工作区在 1440×900、1024×768、800×600 验证；建议图标栏约48、侧栏默认240、可调整200–320、正文舒适宽度720–900，采用 tokens 而非散落硬编码。宽度不足先收辅助面板再折叠侧栏，保留显式展开入口；不得默认整页横向滚动。
标签支持激活、关闭及指定区域打开；通用 close 只关闭视图，是否存在未保存编辑由原编辑 owner 提供，不能把关闭标签当终止 Agent。拖动不是唯一操作方式，应有键盘/菜单替代。
一个 Workbench 弹层管理入口负责 anchor、边界翻转/约束、Portal 根、层级和焦点；ui 负责菜单内容。nested 菜单 Esc 逐层退出、外部点击遵循模态规则、退出返回仍存在的触发点；触发点已卸载时回到合理工作区焦点。不覆盖原生标题栏控制，不设吞掉整窗点击的透明遮罩。自定义内容可接入此层，不私建 z-index 体系。
布局保存仅含安全 UI 偏好，复用 F5 条件写；恢复缺插件显示缺席/移除入口，不自动激活插件、恢复进程或调用模型。无存储适配明确 session-only，不宣称重启恢复。

## 5. 设置容器与控件

设置作为独立可返回的工作区；分类侧栏、搜索、标题、内容容器公共化，不以全屏模态遮罩取代工作区。离开后回到先前工作区/焦点，是否保存由编辑 owner 决定。
设置贡献提供 ID、分类、标题、说明、关键词、字段/自定义编辑器、读取/提交接口；搜索仅索引已声明展示元数据，不检索秘密或全业务正文。无匹配可清除筛选。字段依托 F5 编辑合同，不发明优先级。
简单设置只有提供者声明即时保存才即时提交；复杂资源配置提供保存/取消/dirty/校验/冲突。外部更新不覆盖 dirty，迟到成功不清新编辑。SecretRef 与受信导入沿用原合同，不把 API Key 放表单/布局 store。
基础控件至少覆盖：图标按钮/tooltip、菜单组/子菜单/危险项/快捷键、可选列表行/分组/尾部操作、搜索、tabs、switch、设置行/设置组、折叠区、加载/空/错误/未知反馈。同一组件库统一字号、间距、圆角、状态颜色、焦点、高对比和禁用态；每个图标操作有可访问名称。
不以红色显示正常等待；错误按稳定 ID 更新，不随输入创建提示。业务 unknown 文案由实际结果提供，不自行推断断网。正常时不堆原始诊断文字，详细诊断可展开。

## 6. 领域状态及插件边界

公共包只有布局、焦点、弹层、通用编辑工具的 UI 状态。Agent 配置仍是同域唯一权威；Profile 仅提交声明字段，model 只提交原子配置组，各控件读同一事实和操作投影。选含模型 Profile 后模型显示相应有效配置，未确认时明确待应用而非冒充已确认；没有 model 的 Profile 不清模型。
Chat 的输入/消息/思考/工具事件、Workspace 项目树、会话历史、扩展管理的安装信息均不进入 Workbench。本单用两个中性消费者验证开放入口；生产领域页面的全面 redesign 后续独立审查，不默认包含浏览器/终端/市场/账户体系的新能力。

## 7. 验收场景（增量 UI-A01–12）

每项保存源码提交、命令/退出码、截图或交互记录、失败反例和实际验证层级。缺必需环境标 pending，不能标绿。

| ID | 正向操作与可观察结果 | 反例及拒绝/纠正行为 |
| --- | --- | --- |
| UI-A01 | 两个中性插件分别贡献工作区/侧栏/页面操作；切换只换相关内容，全局栏稳定 | 无 Chat/Profile 启用集照样运行；私有宿主导入或重复入口不能通过 |
| UI-A02 | 同操作从按钮/菜单/快捷键执行，均捕获正确目标并共用可用性 | 菜单开后目标撤销/权限变化，执行拒绝且不作用于新目标 |
| UI-A03 | 窗口四角菜单与嵌套菜单均可见；Esc逐层退出、外部点击退出、焦点恢复 | anchor卸载、内容过长、窄窗口不残留遮罩，不裁切关键操作 |
| UI-A04 | 标签/右侧/底部视图独立激活、关闭、调整；键盘可达 | 关闭视图不取消原业务任务；dirty视图按编辑owner提示 |
| UI-A05 | 三个规定尺寸均能导航、编辑和关闭；辅助区可折叠 | 800宽不要求整页横滚；主区域仍可用，不制造空白常驻面板 |
| UI-A06 | 重启恢复安全布局和展开状态；缺插件给明确降级 | 恢复不激活缺席插件、不创建会话、不启动模型；无存储不声称恢复 |
| UI-A07 | 设置搜索定位两个中性贡献；返回原工作区，复杂字段保存/取消清楚 | dirty遇外部更新保本地值；迟到保存不清新编辑；秘密不进入通用store |
| UI-A08 | 控件统一视觉、键盘焦点、禁用和可访问名称；长标题省略可查看 | 图标无名称、只有hover可操作、暗色/高对比不可读均不能通过 |
| UI-A09 | 连续输入、IME及正常异步状态不闪红字，不丢焦点/草稿 | 注入失败/unknown稳定显示真实原因；不能删错误或宽松放行冒充修复 |
| UI-A10 | 停用插件后导航/菜单/快捷键/订阅撤销，其他插件继续运行 | 晚回调/旧句柄不能更新新代；失败激活不残留贡献 |
| UI-A11 | 三处同目标观察只读事实一致；实例/区域变化不新增领域writer | 演示配置字段覆盖；不存在自建Workbench业务store或第二交互总线 |
| UI-A12 | 干净发行产物的受控Desktop打开工作区/设置/菜单/分屏成功 | 不依赖源码目录、editable或隐式注入样式；仅源码截图不能证明产物通过 |

UI-A01–02/07/10–11 可先有受控集成证据；UI-A03–09 必须补真实浏览器/ Electron 操作，UI-A12 必须产物证据。真实模型调用不属于此合同所需验证。
