# R7 / F5 — 前端插件开发基础设施
决策 M14，2026-10-03。用户批准补齐基础设施并纳入正在执行的026。本文件是新增交付合同，不是实现证明。保留E3/F3、025V4的唯一所有者/观察/草稿原则，不增加全局业务Store或第二关系核心。

## 1. 边界及组织
平台提供机制，领域决定值与业务规则。状态分三类：领域owner事实；来自后端的授权只读投影；独立UI目标的本地状态/编辑草稿。前端不得将缓存、乐观展示或任务状态当作后端确认。
运行时authority槽只存身份/访问/生命周期元数据，不存领域业务值；通用状态容器的实例和值归创建它的owner，由runtime提供工厂而非中央业务仓。
平台工具不含Agent/Profile/model/ACP字段，不能要求Chat才能编辑、查询或通知。非React契约/实现不得依赖React或Electron；React帮助接口有独立exports及同一底层实例。
延用10个frontend包，不新建十几个空包；内部目录名可变，公开职责不可混。

| 包 | 新增/完善责任 | 不应承担 |
| --- | --- | --- |
| extension-api | 状态/任务/界面存储/公共交互的中性类型、Token和能力接口 | 具体存储库、React、业务字段、额外调度 |
| extension-runtime | 状态工厂、作用域退订、异步等待管理、UI存储协调 | 所有业务值的全局Store、后端事务或退出主账 |
| workbench | 通知/进度/选择确认呈现、上下文、设置编辑组织、布局恢复 | 业务授权、保存业务值、加载插件 |
| ui-components | React选择订阅、公共编辑会话及表单绑定工具 | 强制使用某个资源插件、第二DraftOwner |
| ui | 主题/图标/翻译接入的显示工具及基础组件可访问性 | 服务访问授权和秘密 |
| server-bridge | 已授权投影、连续观察、普通只读查询缓存 | 业务写权、另造订阅权限/准入账、自动重发效果 |
| connections | 稳定连接身份/代次与可用性 | 解释业务修订或模型字段 |
| native-bridge | 经宿主授权的存储、OS交互实现 | renderer秘密正文或任意路径读写 |

## 2. 状态容器和选择订阅
owner获得写入口；消费者只得只读snapshot/subscribe和领域自行声明的操作接口。禁止向消费者暴露通用setState，也不能取得内部可变对象。
快照有稳定身份；未变化getSnapshot返回同一对象。发布后消费者不能修改；嵌套值应不可变，不用浅Object.freeze冒充深层安全。版本单调、派生值只计算不建第二写者。
选择器仅在已获授权快照上取字段；equal不变不通知。通知重入可排队但不递归无限发布；批量更新最终只暴露完整一次快照，不承诺跨owner事务。
subscribe返回幂等释放句柄；调用者scope退出自动释放；旧代次dispose/晚回调不得改新owner。只读投影可有缓存，但没有写入口，权限撤销后清可访问快照/排队通知，不声称可撤回已交给插件的数据。
React帮助接口使用同一snapshot来源；提供selector/equality、卸载退订和不可用呈现。无关通知不得写回输入DOM，真实IME仍按025/009验收，不因React单测通过宣称IME已通过。

## 3. 后端投影和普通查询
投影复用E3的readAndSubscribe/cursor/credit/lease；没有第二订阅broker。域提供revision和业务补链规则，桥只维护声明的可读投影、关联和有界缓冲。gap显式标resync-required；完整快照替换旧链，旧scope/连接/授权结果不能覆盖新投影。
普通查询声明为无效果read，按环境、连接代次、授权范围/代次、服务目标、合同版本及参数组成key。同key请求可合并，跨用户/授权/目标不得共享；撤权、退出和连接更换触发隔离/清理。字段过滤在提供者/受信边界执行，不靠客户端selector授权。
查询支持分页、invalidate、显式刷新和容量/生命周期限制，缓存不是完整历史。重试、聚焦刷新、重新连接刷新必须由查询声明和产品策略明确配置，非幂等效果不得伪装成query。
snapshot、连续流、目录列表三种消费者分别标新鲜度；不把请求成功当持续同步，也不为unknown调用模型探测。平台可保存安全UI偏好，不默认持久化业务正文、鉴权结果或秘密。

## 4. 异步任务和取消
任务句柄记录本地等待状态、捕获target/activation/generation、请求关联及取消方式。completion投递前重核scope/目标/权限；A请求晚到不能覆盖B选择。
取消等待仅停止当前消费者等待，不证明后端/原生停止；取消效果只能调用声明的公开能力，并报告其真实结果。已接纳工作仍归原Activity/owner管理，不因视图关闭销毁。
普通任务支持加载/失败/进度呈现；结果未知保留原关联，不自动retry或新建attempt。通用工具不重新实现Submission/Run业务状态机。

## 5. 编辑会话、表单和设置
提供可独立于Chat使用的编辑会话：stable editId、baseRevision、editRevision、dirty字段、错误、保存中关联、冲突提示。正文和值归编辑owner，平台提供实现工具和受限访问，不中央收集。
创建时保存基底，外部更新不得覆盖dirty编辑。提交捕获字段mask/baseRevision/editRevision；领域执行校验和条件写。成功只清同一次提交仍未改变的字段；相同文本ABA/迟到A结果不得清B编辑。
取消只丢本编辑，不撤已接纳保存；冲突保留本地值供人工解决，不默认最后写覆盖。IME缓冲按025规则，普通组件不得借订阅强制重写value。
设置贡献提供稳定ID、展示描述、默认值来源、可编辑范围、校验/读取/提交接口；平台处理通用类型/输入校验和编辑呈现，业务验证归域。默认值和生效规则来自相应owner，不加一套平台业务配置覆盖优先级。
秘密字段只能使用公开SecretRef与受信导入操作，不把API Key放通用表单store、日志或UI持久化。域可贡献自定义编辑器，不能将全部资源强制塞自动表单。

## 6. UI保存和恢复
可注入UI存储按pluginNamespace/workspace/window-or-shared-purpose/schemaVersion分区，支持读取、条件写、删除自有UI记录和迁移；scope释放不默认删除持久偏好。
只保存显式声明的安全UI数据，例如布局、展开ID和筛选；业务正文、凭据、完整会话配置及权限证据不默认保存。领域草稿需领域明确存储合同，不以UI偏好接口绕过数据授权。
宿主提供真实适配，runtime协调；缺适配时明确session-only且不许诺重启恢复。fixture验证未知schema拒写、存储失败保当前UI、插件缺席不自动激活、恢复引用失效有降级。
多窗口共享项用适配方声明的条件写/唯一owner协调；窗口本地项独立目标。缺跨窗口实现拒共享写保证，不用BroadcastChannel或模块单例冒充跨进程权威。

## 7. 公共交互、上下文和显示
Workbench呈现Notification/Progress/QuickPick/Input/Confirm，受scope约束，有稳定句柄和更新/关闭；重复事件可按声明ID更新，不能每次输入新建红色提示。错误展示不得猜测网络已断或操作失败。
进度与取消按钮只投影任务声明；取消请求不立即显示“已停止”。未知结果只提供安全核对入口，不自动重发。
上下文键带命名空间/作用域，从焦点、选中UI目标及已授权投影派生；菜单、按钮、命令面板和快捷键同源判断。when仅展示可用性，执行仍由原公开操作授权；键中不持秘密或另一份当前模型。
i18n接口支持namespace、参数、缺失key回退；图标稳定ID及未知回退；主题含高对比语义。公共选择框/弹层/表单需键盘可达、可读label、焦点恢复，业务插件可用自己的内容但复用公共机制。
局部组件失败不拖垮整个Workbench；诊断脱敏，通知不是操作Receipt主账。
