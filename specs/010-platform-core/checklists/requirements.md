# Specification Quality Checklist

- [x] 四个用户故事均有独立验收与优先级。
- [x] FR-001 至 FR-015 和 SC-001 至 SC-006 可映射任务（含 C6 补充）。
- [x] 明确 scope/non-goals、unknown/缺席与安全边界。
- [x] 方案包含研究取舍、数据模型、公共接缝、验证指南。
- [x] A/B/C 文件所有权与跨线提交依赖明确。
- [x] Connections 通用机制/Agent 规则/UI/native-bridge 的边界分别明确，非整包搬迁；C6 有 CN-01–08 反例。
- [x] 不合入旧业务工作树；不把受控链等同真模型验证。
- [x] 历史迁移采用字节/标识保全，无真实数据迁移授权。
- [ ] A 的 C1 DTO 代码契约检查点尚未交付；B 的 Core 实现任务必须等该门。
- [ ] 三线基线测试尚未执行；旧日志数字不得当本批证据。
- [ ] 最终产品集成/主控审核未执行，不能提前宣称完成。

最后三项是已列任务依赖，不是允许实施者自行决定产品语义。执行中若发现现有调用者需要改变本文件未授权的行为，应报告而非扩张任务。
