## 解释与偏差登记

1. **"clientInfo 支持列表"**：MCP initialize 线上格式只携带单个 `params.protocolVersion`（`clientInfo` 仅 name/version），故"支持列表"落在 `ProbePolicy.supported_protocol_versions`（`("2025-11-25","2024-11-05")`，含需求点名的两版），请求发最新项，协商事实以响应为准并回报 `requested/supported/negotiated` 三元组（`_handshake_facts.negotiation`）。未发明线上字段。
2. **新错误码未入 errors.py**（任务书约束：`PROBE_AUTH_REQUIRED/PROBE_CONNECTION_FAILED/PROBE_CANCELLED/PROBE_PROTOCOL_MISMATCH/PROBE_REDIRECT_REFUSED/PROBE_URL_NOT_ALLOWED` 定义于 probe.py:57-62）。errors.py 中预留的 `AUTH_REQUIRED/CONNECTION_FAILED`（FR-10 词汇表）是**连接级**语义，与 probe 的 `PROBE_` 前缀运行时码不同层；T09 装配如需统一在此登记。
3. **HTTP cancel 是阶段间协作式**（不抢占已阻塞的 socket 读；读超时预算=策略 deadline），stdio 侧因 50ms select 分片 cancel 延迟 ≤50ms。取消语义测试以 stdio 树回收为主证据。
4. `test_http_connection_failed` 依赖本机 `127.0.0.1:9` 无监听（开发机事实；若被占用该例会以红暴露，不改绿）。
5. probe 无凭据运行以 **env/header 白名单 + 排除清单**实现；"带凭据 probe"（解析 secretRef 后经授权注入）不在本任务，属 T05/T07/T10 生产路径，V03 只钉"无凭据 probe 不能宣称凭据可用"。

- 受控 L2 证据级别（fake server initialize）；真实外部 MCP 服务、有凭据 probe、inspectConnection/listTools 分级、wire/描述符注册与 compat 退役均属 T05/T09/T10。
- probe 结果尚未接 `resolve_preview`/审批闸门消费方（T02 快照不依赖 probe 事实，符合"保存不探测"）。
- Streamable HTTP 会话头（`Mcp-Session-Id`/`notifications/initialized` 后续帧）未建模：probe 只证 initialize 握手，正是本级证据的边界；受管连接在 T05 持完整会话。
